# Placement Management System

A web application for managing student placements, built with Java, JSP, Servlets, and MySQL (AI-assisted development).

## Features
- Student registration and login
- Profile management and resume upload
- Application tracking
- Admin module to manage company drives, notifications, and applicant details

## Technologies
Java, JSP, Servlets, HTML, CSS, MySQL, Eclipse IDE, Apache Tomcat

## How to Run
1. Import the project into Eclipse.
2. Create the database using the SQL file.
3. Update the database username and password in the connection file.
4. Run on Apache Tomcat.
